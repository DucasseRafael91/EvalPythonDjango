# Application Competence

## Présentation

Bienvenue sur Application Competence — une interface frontend construite avec Django

Cette application permet de demander ou proposer son aide pour une compétence, de consulter les compétences disponibles, et de gérer les compétences que vous avez proposées ou demandées. 
L'application est conçue pour être facile à utiliser et offre une expérience utilisateur fluide grâce à l'intégration de Bootstrap 5.

----------

## Installation

Effectuer git clone : https://github.com/DucasseRafael91/EvalPythonDjango.git

Puis dans le répertoire du projet :
faire py -m pip install Django==5.2.12 pour installer le framework Django 
faire pip install django-bootstrap5 pour installer le package django-bootstrap5

## Fonctionnalités

Cet application permet de gérer les compétences, avec des fonctionnalités telles que :
- Création, lecture, mise à jour et suppression de compétences
- Interface utilisateur conviviale avec Bootstrap 5
- Journalisation des activités pour suivre les actions des utilisateurs
- Gestion de roles et permissions pour sécuriser l'accès aux fonctionnalités
