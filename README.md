# 📌 Polymarket

## 🚀 Présentation

Bienvenue dans **Polymarket** — une interface frontend construite avec **React** et **Vite**.  
Ce projet est une reproduction du site polymarket a des fins pedagogiques

----------

## 🧱 Structure du projet

Voici les principaux dossiers et fichiers :

```
📦 evalPythonDjango-
 ┣ competences/ # Application Django pour gérer les compétences
 ┣ doc/ # Documentation et ressources
 ┣ logs # Journalisation des activités
 ┣ mysite # Projet Django principal
 ┣ templates/ # Templates contentant le gabarit parent
 ┣ manage.py/ # Script de gestion Django
 ┣ 📜 README.md # Ce fichier 
 ┣ 📜 .gitignore # Fichiers ignorés Git` 
```
----------

## Installation

Effectuer git clone : https://github.com/DucasseRafael91/EvalPythonDjango.git

Puis dans le répertoire du projet :
faire py -m pip install Django==5.2.12 pour installer le framework Django 
faire pip install django-bootstrap5 pour installer le package django-bootstrap5

## 🧠 Fonctionnalités

Ce modèle inclut :

-   🌀 **React** avec support de composants modernes.
-   ⚡ **Vite** pour un développement ultra‑rapide avec rechargement à chaud.
-   🧩 Structure prête à étendre pour futurs composants et pages.
